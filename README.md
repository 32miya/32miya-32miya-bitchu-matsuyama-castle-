# 備中松山城さんぽ

現存天守でただひとつの山城・備中松山城（岡山県高梁市）の天守と城下を、スマホで歩いて巡れる3D散策アプリの試作品。three.js製の単一HTMLです（「彦根城さんぽ」「大阪城さんぽ」と同じ仕組み）。

- 時代を選ぶ（メニューの「時代」）: 現代 / 江戸時代（19世紀前半ごろ・板倉家の松山藩の想像復元）
- 時刻を「朝」にすると、盆地が霧に埋まって天守が雲海に浮かびます（城下やふもとは霧の中）
- 臥牛山（がぎゅうざん）: ふもとの御根小屋 → 登城道 → 下太鼓の丸 → 中太鼓櫓跡 → 大手門跡（岩盤と石垣）→ 三の平櫓東土塀 → 三の丸 → 厩曲輪 → 二の丸 → 本丸南御門 → 本丸（天守）→ 後曲輪（二重櫓）。ふいご峠からの道も中太鼓の丸で合流します
- 天守（重要文化財）: 二重二階。南面に向唐破風の出格子窓、腰は黒い下見板張り。東の入口から天守台の中の階段を上って1階へ。1階に囲炉裏と装束の間、2階に御社壇。各階の連子窓から外の景色が見えます
- 現存・復元の建物: 天守・二重櫓・三の平櫓東土塀（重要文化財）、本丸南御門・五の平櫓・六の平櫓・東御門・本丸の土塀（平成の復元）、八の平櫓の石垣
- 江戸時代だけ: 大手門と左右の櫓、黒門、二の丸の櫓門、二〜九の平櫓の一部、中太鼓櫓・下太鼓櫓、足軽番所、曲輪をめぐる土塀、御根小屋の御殿、藩校 有終館、高梁川の高瀬舟、城下の人々
- 城下: 石火矢町ふるさと村（武家屋敷）、本町の町家、紺屋川筋（桜と柳）、頼久寺（枯山水の庭）、高梁基督教会堂（現代）
- 入れる建物: 現代＝武家屋敷館（旧折井家）・頼久寺の書院・商家資料館 池上邸 / 江戸時代＝御根小屋の表御殿・武家屋敷の書院・本町の商家・頼久寺の書院・有終館の講堂
- 段差は約1.3mまでしか上り下りできません（石垣から落ちません）。山の林の斜面には入れず、曲輪・石段・道を歩きます
- 名所の写真は Wikimedia Commons から検索して表示します（撮影者・ライセンスを併記）
- 距離と高さは実際よりかなり縮め、建物の配置と寸法も簡略化しています。天守の入口まわりや御根小屋・城下の建物の配置は想像を交えています

URLの末尾に `?era=edo` を付けると江戸時代から始まります。

公開URL: https://32miya.github.io/32miya-32miya-bitchu-matsuyama-castle-/

## お城さんぽシリーズ共通
- 人物・旗・襖絵・床板・石垣などの素材は、シリーズ共通の `https://32miya.github.io/oshiro/common/assets/` から読み込みます（このリポジトリに同じ画像を置かない）。一覧と使い方は `32miya/32miya.github.io` の `oshiro/common/README.md`。
- 天守の窓は本当の開口にして、各階の中から外の景色が見えるようにする（シリーズ共通の作り）。
- index.html の末尾の `oshiro-portal:begin`〜`end` は「お城選びへ戻る」ボタンなので消さない。
- 備中松山城で新しく作った材質（コードで描画）: 下見板張り `itaK`、下見板＋漆喰の櫓の壁 `wallBK`、臥牛山の岩盤 `rock`、矢狭間・鉄砲狭間の土塀 `dobeiB`、囲炉裏の灰 `hai`、枯山水の砂紋 `samon`。
